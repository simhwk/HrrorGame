# PPT 생성용 프롬프트 (복사해서 AI에 붙여넣기)

```
아래 게임 기획을 바탕으로, 10개 섹션 순서대로 PPT 슬라이드 초안을 작성해줘.
슬라이드 제목 + 불릿포인트 위주로, 문장은 짧고 명확하게.
표로 정리하라고 되어 있는 부분은 반드시 표 형태로.
이미지가 필요한 슬라이드는 "[이미지 삽입: 어떤 이미지가 필요한지]"로 표시해줘.
"미정"이라고 적힌 항목은 내용을 지어내지 말고 "미정 (기획자 확인 필요)"라고 그대로 표시해줘.

---

[게임 정보]
- 게임 제목: 미정
- 장르: 1인칭 파운드푸티지 공포
- 플랫폼: PC / Unity (3D)
- 한 줄 컨셉: 친구를 따라 들어간 하수구에서, 앞서간 친구가 남긴 표식을 따라 나아가지만
  그 표식조차 점점 믿을 수 없게 되어가는 20분 내외 단일 세션 공포 게임
- 개발 규모: 미정
- 참고 게임: Iron Lung, 8번 출구(Exit 8)

---

1. High-Level Vision
- 엘리베이터 피치: 친구를 따라 들어간 하수구에서, 앞서간 친구가 남긴 표식을 따라 나아가지만
  그 표식조차 점점 믿을 수 없게 되어가는 20분 내외의 1인칭 파운드푸티지 공포 게임.
- 레퍼런스 + 차별점: Iron Lung(폐쇄 공간, 안 보이는 위협), 8번 출구(갈림길+단서 확인 루프) 참고.
  차별점은 정답을 판정해서 되돌리는 구조가 없다는 것 — 표식의 신뢰도 자체가 무너지는 게
  핵심이라 공략이 성립하지 않음.
- 플랫폼: PC / Unity (3D)
- 비즈니스 모델: 미정

2. Art Style / Theme
- 무드보드: [이미지 삽입: 하수구 콘크리트 벽, 습기·녹·오물 텍스처 / VHS·캠코더 파운드푸티지 스틸컷]
- UI 스타일: 캠코더 오버레이 — 타임스탬프, 배터리, REC 표시, 노이즈·스캔라인
- 환경 톤: 어둡고 습하고 더러움. 광원은 캠 조명 하나 (엔딩 제외)
- 캐릭터 스타일: 해당 없음 — 캐릭터·크리처 모델링을 만들지 않음 (위협은 비가시적으로 연출)
- 렌더링/시점: 1인칭 핸드캠 (파운드 푸티지)
- 연출 참고 클립: 미정

3. Story
- 핵심 서사: 플레이어는 친구를 따라 담력체험 삼아 하수구에 들어간다. 먼저 사라진 친구가
  벽에 표식을 남겨뒀고, 이를 따라 나아간다. 표식은 점점 신뢰할 수 없게 변하고, 결국 어떤
  길을 택해도 마지막엔 무언가에게 습격당해 죽는다.
- 전달 방식: 오프닝은 친구와의 대화(형식 미정). 본편은 환경 스토리텔링(핏자국, 떨어진 신발,
  신음소리)으로 전달. 컷신은 엔딩에서만 사용.

4. Core Loop
- 루프 다이어그램: [갈림길 도착] → [표식 관찰] → [방향 판단] → [이동] → 반복(루프마다
  이상현상 강도 누적) → [엔딩 트리거: 빛 발견] → [질주] → [습격] → [캠 낙하, 종료]
- 핵심 시스템: 이상현상 상태 관리(루프에 따른 6종 에셋 트랜스폼·사운드 변화), 플레이어 상태
  연출(숨소리·시야 왜곡)
- 메타 시스템: 없음 — 단일 세션, 저장·재도전 없음
- 주요 화면: 캠 화면 (오프닝 대화 화면은 별도일 수 있음, 형식 미정)
- 화면 간 이동: 오프닝 → 본편(캠 시점 반복) → 엔딩 컷신 → 종료
- 핵심 변수: 루프 카운트(이상현상 단계 결정), 플레이어 상태 레벨 — 세부 수치는 미정

5. Screens, UI, UX
- 캠 화면: 화면 전체가 캠 뷰파인더. 상/하단에 타임스탬프·배터리·REC 표시. 노이즈·스캔라인이
  전체에 오버레이.
- 핵심 UI 요소: REC 인디케이터, 배터리 표시(연출용 — 실제 자원 관리 시스템 여부는 미정),
  노이즈 강도(루프에 따라 증가)
- 화면 전환: 오프닝 종료 → 캠 On(본편 시작) → 엔딩 트리거 시 컷신 → 캠 낙하로 종료
  (플레이어 조작에 의한 메뉴 전환 없음)

6. Game Economy
- 해당 없음. 재화·수치 시스템을 쓰지 않는 게임이므로 이 섹션은 슬라이드 1장으로
  "해당 없음"만 명시하고 넘어가줘.

7. Asset List
다음 표를 그대로 슬라이드에 옮겨줘.

| 에셋명 | 종류 | 제작 방식 | 우선순위 |
|---|---|---|---|
| 벽면 배관 파이프(파손) | 3D 프랍 | 직접 제작 | 높음 |
| 배수 철망(그레이트) | 3D 프랍 | 직접 제작 | 높음 |
| 벽 낙서/스프레이 표식 | 3D 프랍(데칼 가능) | 직접 제작 | 최상 (핵심 단서) |
| 천장 체인 | 3D 프랍 | 직접 제작/에셋팩 | 중간 |
| 쓰레기·잔해 더미 | 3D 프랍 | 에셋팩 활용 가능 | 중간 |
| 사다리 (엔딩용) | 3D 프랍 | 직접 제작 | 높음 |
| 캠코더 UI 오버레이 | UI/셰이더 | 직접 제작 | 최상 |
| 공포 음원(정체불명 소리·신음·습격음) | 사운드 | 기성 음원 | 최상 |

비고: 떨어진 신발은 신규 에셋 여부 미확정 (6종 교체 / 잔해더미에 포함 / 엔딩 예외 7번째
중 택 1 필요) — 이 비고를 슬라이드에도 그대로 남겨줘.

8. Level Schema and Sample Level Design
- 전체 구조: 레벨 개념 없음. 작은 T자형 맵 하나를 반복 순회.
- 아래는 루프별 배치 "예시안"이며 미확정이라는 점을 슬라이드에 반드시 표시해줘.

| 루프 | 사건 |
|---|---|
| 1 | 표식 정상. 멀리서 친구 이름 부르는 소리 |
| 2 | 표식 복제(두 개) |
| 3 | 신발 발견. 표식 신뢰 흔들리기 시작 |
| 4 | 표식 훼손/소실 |
| 5 | 핏자국. 여러 방향에서 소리가 겹침 |
| 엔딩 직전 | 파이프에서 친구 신음소리 → 빛 발견 |

- 레벨 에디터: 불필요. 고정 배치 + 코드 상태 전환.

9. First Time Experience
- 온보딩: 별도 텍스트 튜토리얼 없음. 오프닝 대화(친구와 담력체험 설정)로 자연스럽게 진입.
- 반드시 전달돼야 하는 것: "표식 = 방향 단서"라는 규칙 — 친구가 남겼다는 서사로 암시.
  명시적 튜토리얼 텍스트 없음.
- 소요 시간: 오프닝 포함 전체 20분 이내.

10. Team, Schedule, Budget
- 미정. 이 섹션은 "내부 계획용 — 추후 별도 작성" 한 줄만 넣고 넘어가줘.
```
