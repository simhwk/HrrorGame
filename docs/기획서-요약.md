# 기획서 요약

> 전체 상세 버전은 `docs/기획서.md` 참조.

## 기본 정보
- 장르: 1인칭 파운드푸티지 공포 / 플랫폼: PC·Unity(3D) / 러닝타임: 20분 이하 단일 세션
- 원칙: 이상 요소는 누적시킨다

## 무대 · 컨셉
- 무대는 동굴. 친구를 따라 담력체험 삼아 들어갔다가, 먼저 사라진 친구가 남긴 표식을 따라 나아간다.
- 시점: 핸드캠(캠코더). 화면은 캠코더 저화질 필터(노이즈·스캔라인·색수차)로 표시되지만, 실제 3D 에셋 품질은 낮추지 않는다.
- 아트 레퍼런스: 몸이 겨우 통과하는 좁은 통로, 젖은 진흙 벽, 종유석/석회질 침전물, 고인 물, 헤드램프 하나만의 조명.
- 참고작: **Iron Lung** — 폐쇄 공간, 저화질, 위협을 안 보여주고 소리로만 존재하게 하는 방식.

## 진행 구조
- T자형 갈림길이 반복되는 작은 맵(공간 1개 원칙). 총 **7루프**.
- 표식이 천장 높이 변화에 따라 3단계로 바뀐다:
  1. **테이프** (160cm, 서서 이동) — 3루프
  2. **가이드라인/실** (100cm, 구부려 이동 — 시야 확보가 안 돼서 손으로 만지는 방식으로 전환) — 3루프
  3. **핏자국** (마지막 분기, 단서가 아니라 결과만 남음) — 1루프
- 어떤 길을 택해도 결국 죽는다 — 진짜 분기가 아닌 가짜 선택. 판정형 분기·재시작 신호는 없음(학습되면 무서움이 아니라 공략이 되므로).
- 루프마다 크리처 암시가 누적: 멀리서 나는 소리 → 표식 이상 → 입김·발소리 리듬 → 조명 깜빡임·장비 훼손 → 등 뒤 정적. 형체는 끝까지 안 보여준다.

## 에셋 6종
케이빙 테이프 / 가이드라인 로프 / 낙석 더미 / 낡은 지지대 / 버려진 탐사 장비(친구 흔적 + 신발 포함) / 엔딩용 "빛 드는 틈"

## 친구의 결말
시체 에셋 없이 암시만: 핏자국, 신발(탐사 장비 더미에 포함), 고통스러운 소리. 엔딩 직전 벽 틈에서 신음소리.

## 엔딩
핏자국 → 컷신 진입 → 카메라 낙하 → 사운드로만 습격 처리(고기 뜯기는 소리 + 크리처 울음) → 떨어진 각도 그대로 빛 드는 탈출구가 비치며 종료.

## 예외 규정
공간 1개 / 컷신 금지 / 광원 1종은 본편에만 적용. 엔딩은 별도 공간으로 취급해 컷신과 추가 광원을 허용한다.
