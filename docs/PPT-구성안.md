# GDD PPT 페이지별 구성안 (v2 — 동굴판)

> `docs/기획서.md` 기준 최신화. 에셋 상세 목록과 루프별 상세 진행은 이 문서에서 제외 (원본 기획서 4장·9장 참조).

---

## 1. High-Level Vision

- **엘리베이터 피치**: 친구를 따라 들어간 동굴에서, 앞서간 친구가 남긴 표식을 따라 나아가지만 그 표식조차 점점 믿을 수 없게 되어가는 20분 내외의 1인칭 파운드푸티지 공포 게임.
- **레퍼런스 + 차별점**: Iron Lung(폐쇄 공간, 안 보이는 위협), 8번 출구(갈림길+단서 확인 루프) 참고. 차별점은 정답을 판정해서 되돌리는 구조가 없다는 것 — 표식의 신뢰도 자체가 무너지는 게 핵심이라 공략이 성립하지 않음.
- **플랫폼**: PC / Unity (3D)
- **비즈니스 모델**: 미정

## 2. Art Style / Theme

- **무드보드**: [이미지 삽입: 동굴 탐험 레퍼런스 사진 — 몸이 겨우 통과하는 좁은 통로, 젖은 진흙 벽, 종유석/석회질 침전물, 고인 물, 헤드램프 조명]
- **UI 스타일**: 캠코더 오버레이 — 타임스탬프, 배터리, REC 표시, 노이즈·스캔라인
- **환경 톤**: 어둡고 습함. 천장 높이가 160cm에서 100cm로 점점 낮아지며 압박감이 커짐
- **캐릭터 스타일**: 해당 없음 — 캐릭터·크리처 모델링을 만들지 않음. 위협은 소리·화면 효과로만 존재
- **렌더링/시점**: 1인칭 핸드캠 (파운드 푸티지)
- **연출 참고 클립**: 미정

## 3. Story

- **핵심 서사**: 플레이어는 친구를 따라 담력체험 삼아 동굴에 들어간다. 먼저 사라진 친구가 남긴 표식을 따라 나아가지만, 표식은 점점 신뢰할 수 없게 변하고, 결국 어떤 길을 택해도 마지막엔 무언가에게 습격당해 죽는다.
- **전달 방식**: 오프닝은 친구와의 대화(형식 미정). 본편은 환경 스토리텔링(흔적, 소리)으로 전달. 컷신은 엔딩에서만 사용.

## 4. Core Loop

- **루프 다이어그램(개괄)**: [갈림길 도착] → [표식 확인] → [방향 판단] → [이동] → 반복(반복될수록 이상현상 강도 상승, 표식 매체도 단계적으로 전환) → [엔딩 트리거] → [컷신] → 종료
- **핵심 시스템**: 이상현상 상태 관리(루프 진행에 따른 강도·매체 전환), 플레이어 상태 연출(숨소리·시야 왜곡)
- **메타 시스템**: 없음 — 단일 세션, 저장·재도전 없음
- **주요 화면**: 캠 화면 (오프닝 대화 화면은 별도일 수 있음, 형식 미정)
- **화면 간 이동**: 오프닝 → 본편(캠 시점 반복) → 엔딩 컷신 → 종료
- **핵심 변수**: 루프 진행도(표식 매체·이상현상 강도를 결정), 플레이어 상태 레벨 — 세부 수치는 미정

## 5. Screens, UI, UX

- **캠 화면**: 화면 전체가 캠 뷰파인더. 상/하단에 타임스탬프·배터리·REC 표시. 노이즈·스캔라인이 루프 진행에 따라 강해짐.
- **핵심 UI 요소**: REC 인디케이터, 배터리 표시(연출용 — 실제 자원 관리 시스템 여부는 미정), 노이즈 강도
- **화면 전환**: 오프닝 종료 → 캠 On(본편 시작) → 엔딩 트리거 시 컷신 → 캠 낙하로 종료 (플레이어 조작에 의한 메뉴 전환 없음)

## 6. Level Schema (전통적 "레벨" 없음 — 구조만 요약)

- **전체 구조**: 별도의 여러 공간이 아니라, 작은 T자형 맵 하나를 반복 순회하는 구조.
- **공간 변화**: 천장 높이가 낮아지며(약 160cm → 약 100cm) 이동 방식과 표식 매체가 단계적으로 바뀜.
- **총 반복 횟수**: 7회 (세부 구성은 기획서 9장 참조, 본 PPT에서는 생략)
- **레벨 에디터**: 불필요. 고정 배치 + 코드 상태 전환.

## 7. First Time Experience

- **온보딩**: 별도 텍스트 튜토리얼 없음. 오프닝 대화(친구와 담력체험 설정)로 자연스럽게 진입.
- **반드시 전달돼야 하는 것**: "표식 = 방향 단서"라는 규칙 — 친구가 남겼다는 서사로 암시. 명시적 튜토리얼 텍스트 없음.
- **소요 시간**: 오프닝 포함 전체 20분 이내.
