## 1. 루프 시스템 (가장 중요)

### 구조
```
 z=30   [B: LoopEndTrigger x=24]     [b: LoopEndTrigger (1) x=0.1]   끝선 2개 → 둘 다 같은 시작점으로
 z≈12   ──────── 갈림길 ────────
 z=5            [C: LoopCheckpoint]    중간 체크포인트 (갈림길 전 외길)
 z=0              (스폰)
 z=-18          [A: LoopStartAnchor]   시작선 (역주행 판정 + 순간이동 기준점 겸용)
```
- 모든 선의 파란 화살표(forward)는 **+Z = 정주행 방향**이어야 한다.
- `LoopSafetyWalls`: B·b 2.5m 앞, A 2.5m 뒤의 투명 벽 (최후 안전망). 2회차 "반대편 길"이 이쪽을 지나면 꺼야 한다.

### 판정 방식 — `Level/LoopTrigger.cs`
- **물리 트리거 이벤트(OnTriggerEnter/Exit)를 쓰지 않는다.** 물리는 0.02초마다 겹침만 확인해서, 빠른 이동이나 프레임 렉(0.33m/프레임 이상)이면 선을 건너뛰는 **터널링**이 있었다 ("가끔 트리거가 뚫려 벽에 막힘"의 원인).
- 대신 `LateUpdate`에서 **지난 위치→지금 위치 선분이 선의 면을 가로질렀는지** 계산 (박스 폭·높이 안에서만 유효).
- 한 프레임 5m 이상 이동은 순간이동으로 보고 무시.
- `LoopManager.Teleported` 이벤트로 순간이동 즉시 모든 선이 기준 위치를 다시 잡는다 (안 하면 순간이동 다음 프레임 판정이 빠짐).

### 처리 규칙 — `Level/LoopManager.cs`
| 이벤트 | 처리 |
|---|---|
| 끝선 정주행 통과 + 체크포인트 통과함 | A 너머로 **상대 순간이동** → 루프 +1 → 체크포인트 초기화 |
| 끝선 정주행 통과 + 체크포인트 안 거침 | 순간이동만 (루프 그대로) — 워프 지점 왕복 편법 차단 |
| 마지막 루프(7)에서 끝선 + 체크포인트 | 엔딩 시작 (순간이동 없음) |
| 시작선 A 역주행 | B(x=24) 앞으로 순간이동만 |
| 체크포인트 | 앞으로 넘으면 true, 뒤로 넘으면 false |

- **상대 순간이동**: 넘은 선 기준 상대 위치·방향을 도착 선 기준으로 그대로 옮김 (높이는 월드값 +0.1m). 도착점이 트리거 안이 되어 핑퐁되던 버그, 0.5초 쿨다운 제거.
- 테스트: 이동량 0.2~2m/step(=10m/s·50~5fps) × 정석/변칙 10종 = 60/60 통과.

## 2. 루프별 몸 변화
- 강제 웅크림: 루프 4~6 (`forcedCrouchFromLoop/ToLoop`).
- 루프 7: 웅크린 채 시작, 웅크리기 키를 눌렀다 떼면 일어섬 (`PlayerController.HoldCrouchUntilRelease`).
- **삭제됨**: 몸 커지기(grow) 기능 전체, `CeilingZone.cs`(천장 구역 웅크림) — 씬에서 안 쓰였음.

## 3. 플레이어 (`Player/PlayerController.cs`)
- 서 있을 때 캡슐 2.58m(이전의 1.5배), 웅크림 1.25m. 눈 = 캡슐 꼭대기 −0.12m, 손은 눈 기준 오프셋.
- 벽/천장 관통 방지: 카메라 near clip 0.3→0.05, 눈을 항상 캡슐 안에, `ClampEyeBelowCeiling`(일어설 때 천장 SphereCast).

## 4. 오디오 (`Audio/PlayerAudioController.cs`)
- 웅크린 채 이동 시 **기어가는 소리**: 끌림 루프(`bsb__feet_on_pebbles`, pitch 0.8, 랜덤 시작점) + 손·무릎 짚음(Fantozzi 모래 발소리, mud02) + 옷 스침(kenney cloth1~4, 60%).
- 전용 CC0 기어가는 소리는 못 찾음 — 직접 녹음 또는 Freesound(로그인 필요) 권장.

## 5. 레벨/표식
- `CrouchMap` 루트에 `MarkerPoint` 추가 → 루프 4~6에 제대로 나타남 (이전엔 켜 줄 주체가 없어 안 보였음). `Tunnel1`은 루프 4만.
- `MarkerVariant`는 반드시 `MarkerPoint`가 있는 오브젝트 아래에 둘 것.
- 무너진 케언(`Cairn_Collapsed.prefab`): 완성본 중간 높이까지 쌓였다 무너진 형태, 오른쪽(+X)으로 떨어진 돌 다수.
- 가이드라인: `Assets/Martirial/Guideline.mat` (어두운 갈색, 어둠 속에서 잘 안 보이게).
