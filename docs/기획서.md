# [가제] 야간 주차 관리원 — 기획서 (v0.6)

> **v0.5 대비: 미확정 제안을 전면 삭제.** 수치·시스템·연출 아이디어 중 확정되지 않은 항목을 걷어내고,
> 확정 사항과 미정 항목만 남긴다.
>
> **문서 원칙**: 창작 결정은 기획자가 한다. 이 문서에는 확정된 것과 미정인 것만 적고,
> 미확정 제안은 넣지 않는다.

## 1. 게임 개요

- **장르**: 1인칭 심리 공포 / 내러티브 워킹 시뮬레이터 (반복 업무 기반)
- **플랫폼**: PC
- **플레이 시간**: 15~25분 단일 세션 목표 (하룻밤 완결)
- **핵심 테마**: 지루하도록 정상적인 반복 업무가, 눈치채기 힘든 단계부터 서서히 붕괴하는 리미널 스페이스 공포
- **레퍼런스**: *Iron Lung*, *Fears to Fathom: Ironbark Lookout*, *Clover Pit*(정보 패널 배치), 리미널 스페이스 장르 전반

---

## 2. 핵심 루프

```
차량 진입 → 검사(부스) → 순찰(주차장) → 복귀 → 대기 → 다음 차량
```

### 2-1. 검사와 순찰의 역할 분담 (★확정)

| 행동 | 비중 | 역할 |
|---|---|---|
| **순찰** | **60** | 이상을 **확인**한다 |
| **검사** | **40** | 이상을 **감지**한다 |

- 검사에서 "뭔가 이상한데?"를 먼저 느끼고, 순찰에서 그것을 직접 확인하러 나간다.
- 부스는 좁고 **창문이 없는** 고정 공간. 플레이어의 물리적 이동 대부분은 순찰 구간에서 발생.

---

## 3. 순찰 (★확정)

**규정 주차시간을 초과한 차량에 위반 딱지를 부착한다.** 차량 처리마다 실행되는 고정 루틴.

- 딱지를 붙이려면 차량 바로 앞까지 가야 한다.
- 정상 단계에서는 사무적 이유로, 이상현상 단계부터는 이상을 확인하는 창구로 기능한다.

---

## 4. 부스 구성 (★확정)

**창문 없음.** 바깥 정보는 화면 경유. Clover Pit식으로 좁은 부스에 패널을 몰아 배치해 한눈에 파악 가능하게 함.

- 책상 / CCTV 모니터(다수) / 무전기 / 근무일지
- 그 외 패널 구성은 **미정** — 6장 검사 시스템이 확정되어야 결정 가능

---

## 5. 맵 구조 (★확정)

### 5-1. 기본 성격
**야외 노상 주차장, 심야, 도시 외곽.**

### 5-2. 규모
| 항목 | 값 |
|---|---|
| 총 주차 칸 | **20칸** |
| 근무 시작 시 주차 차량 | **5대** |
| 근무 중 입차 차량 | **6대** (1~6호. 7호는 오지 않음) |
| 최대 동시 점유 | 11대 / 20칸 |

### 5-3. 배치
- **중앙 주 통로 1개.** 통로 양쪽에 직각 주차, **차 머리가 통로를 향한다.**
- 좌우 각 10칸. **5칸마다 가로수 화단**을 배치 → 각 열이 5칸 블록 2개로 나뉜다.
- 부스는 진입로 옆.

```
              ▓▓▓  부지 끝  ▓▓▓

   좌 6~10 ▮▮▮▮▮  │  ▮▮▮▮▮ 우 6~10
             ▲▲▲▲▲  │  ▲▲▲▲▲      ← 차 머리가 통로를 향함
   ── 화단 ──────  │  ────── 화단 ──
             ▲▲▲▲▲  │  ▲▲▲▲▲
   좌 1~5  ▮▮▮▮▮  │  ▮▮▮▮▮ 우 1~5
                     │
                  주 통로
                     │
            ┌────┐   │
            │부스│───┘
            └────┘
                     ↓ 진입로
```

> 5칸 블록이 4개(좌앞·우앞·좌뒤·우뒤) 나온다. CCTV 4분할과 대응시킬지는 **미정**.

### 5-4. 시간 (★확정)
| 항목 | 값 |
|---|---|
| 규정 주차시간 | **30분** (초과 시 딱지) |
| 차량 입차 간격 | **10분** (게임 내) |

→ 산술 결과: 차량은 입차 후 **3사이클 뒤** 규정시간을 초과한다. 7사이클 = 게임 내 70분 근무.

> 딱지 대상이 어떤 순서로 발생하는지(초과 스케줄)는 **미정.**

---

## 6. 검사 시스템 — **미정**

부스에서 무엇을 확인하는지 확정되지 않았다. **다음 작업의 최우선 항목.**

- 원안(v0.1)에는 **번호판 확인 + 요금 확인**이 있었다. 요금 축은 유지한다.
- 요금 외에 어떤 항목을 검사할지 전체 확정 필요.
- 검사는 **이상을 감지하는 쪽**이므로, 각 항목이 이상현상 단계에서 어떻게 어긋나는지도 함께 정해야 한다.

---

## 7. 세션 구조 — 총 7회 (★확정)

**정상 3회 → 이상현상 4단계.**

### 7-1. 정상 단계 (1~3호)

| 차량 | 목적 |
|---|---|
| **1호** | 튜토리얼 시작. 처리 후 최초 순찰 |
| **2호** | 튜토리얼 지속. 검사 항목 소폭 추가 |
| **3호** | 튜토리얼 종료 + 권태 구간. 의도적으로 늘어지는 정적 |

> 설계 원칙: 1~3호에서 겪는 모든 디테일이 이후 "무엇이 달라졌는가"의 기준선이 된다.
> **여기서 절대 힌트를 주지 않는다.**

### 7-2. 이상현상 단계 (4~7호, 누적 방식)

| 단계 | 차량 | 내용 |
|---|---|---|
| **1단계** | 4호 | CCTV 화면 4개 중 1개 파손 / 번호판 없음 등 — **판정 자체가 불가능한 첫 사례** |
| **2단계** | 5호 | 요금 미발생(정산 불가) + **1단계 요소 전부 재등장** + CCTV 화면 자체의 시각적 이상 + 순찰 중 바깥 풍경이 미세하게 변화 (자세히 봐야 인지 가능 — 확신을 주면 안 됨) |
| **3단계** | 6호 | 이상 심화. **공간 구조 자체가 크게 변형** — "장소가 말이 안 됨"으로 무게중심 이동 |
| **4단계** | 7호 (절정) | 차량이 오지 않음. 대신 **사람 같지 않은 무언가가 서 있음**. **요금 창에 비정상적 표시**(`444444`류 반복 숫자). 순찰 시 공간이 전면적으로 변형되어 있음 → **추격 시퀀스 시작** |

> 설계 원칙: 이상 요소는 **누적**시킨다. 크리처/직접적 존재는 4단계에서만 등장시켜
> 3단계까지는 리미널 스페이스 특유의 "공간의 공포"를 최대한 유지.

---

## 8. 추격 시퀀스 (★확정 — 뼈대)

7호에서 최대치의 이상함을 인지한 상태로, **겁먹은 채** 순찰을 나선다.

1. **목격** — 부스 맞은편에서 사람 형체가 달려온다. 놀라서 **부스 안으로 도망쳐 들어간다.**
2. **재출격** — 다시 확인하러 나간다. *(나가는 이유는 **미정**)*
3. **추격** — 나가는 순간 **플레이어 등 뒤에서** 사람 형상이 달려온다. 이상하게 변형된 주차장을 달려서 도주.

### 8-1. 종착점 — **미정**
두 방향을 검토 중:
- (a) 미로형 (*Poppy Playtime* 참고)
- (b) 넓고 이상한 공간에 문 하나만 덩그러니 놓인 형태

### 8-2. 게임오버 (★확정)
- **사망 있음.** 잡히면 게임오버.
- **체크포인트 재시작.** 처음부터 다시 시키지 않는다. *(체크포인트 지점은 미정)*

## 10. 오프닝 시퀀스

| 순서 | 내용 |
|---|---|
| 1 | 주차장 입구에서 도보로 진입 (자유 이동) |
| 2 | 혼잣말 — "늘 똑같은 하루" 뉘앙스로 일상성과 권태감을 먼저 심음 |
| 3 | 부스 진입, 내부 짧은 자유 탐색 |
| 4 | 무전기 사용 유도 — 최초 교신 |

## 11. 스토리 구조 (3층)

| 층위 | 내용 |
|---|---|
| 1층 — 표면 목표 | 규정대로 주차장을 관리하며 근무를 완수한다 |
| 2층 — 이번 근무의 미스터리 | 왜 CCTV가 이상한지, 왜 공간이 변하는지 |
| 3층 — 배경 진실 | 이 부지/전임자/회사와 관련된 배경 — 무전·메모 등으로 서서히 암시 |

- **결말 미정.** 스토리는 이 게임의 핵심이므로 급히 정하지 않는다.

---

## 12. 톤 & 페이싱

- Slow-burn: 정상 단계(1~3호)는 실제로 지루하게 설계 — 여기서 쌓은 지루함이 대조 효과의 재료
- 이상현상 단계부터 침묵 구간과 이상 신호의 비율을 서서히 조정, 4단계에서 절정
- 크리처/직접 위협은 최후(4단계)까지 유보

---

## 13. 미정 사항

**우선순위 순**
1. [ ] **검사 시스템의 항목 전체** (6장) — 요금 + 그 외
2. [ ] 검사 항목별 이상현상 발현 방식
3. [ ] 딱지 대상 초과 스케줄 (어느 차가 언제, 어느 위치에서 초과되는가)
4. [ ] 추격 종착점 — 미로형 vs 넓은 공간 + 문
5. [ ] 추격 2비트에서 다시 나가는 이유
6. [ ] 체크포인트 지점
7. [ ] 부스 패널 구성 (검사 시스템 확정 후)
8. [ ] CCTV 4분할과 맵 블록의 대응 여부
9. [ ] 결말 방향 / 3층 배경 진실
10. [ ] 무전 대사 스크립트
11. [ ] 사람 형상의 비주얼 수위
