# [무제] 기획서

> 주차장 기획(v0.1~v0.6)은 폐기. 전체 이력은 git 히스토리에 있다.
> 제작 예산은 `docs/제작-제약.md` 참조.

## 1. 설계 방향 (★확정)

**압박으로 간다.**

```
압박  →  패닉
압박 + 통제 곤란  →  극심한 패닉
```

- 이 게임의 공포는 분위기가 아니라 **플레이어의 실제 인지 부하**에서 나온다.
- 플레이어를 몰아붙이고, 그 상태에서 통제력을 빼앗아 패닉을 만든다.

## 2. 유지되는 것

- **장르**: 1인칭 공포
- **플랫폼**: PC / Unity (3D)
- **러닝타임**: 20분 이하 단일 세션
- **원칙**: 이상 요소는 **누적**시킨다

## 3. 폐기된 것

주차장이라는 무대 전체 — 부스·CCTV·순찰·딱지·차량·추격·야외 부지 등 여기 딸린 모든 설정.

## 4. 설계 방향이 요구하는 것 (기계적 귀결)

압박→패닉 구조가 성립하려면 아래가 따라온다. 창작 결정이 아니라 조건이다.

1. **동시 처리가 있어야 한다.** 한 번에 하나씩만 처리하면 패닉이 오지 않는다. 밀리는 일이 겹쳐야 한다.
2. **압박의 원천이 필요하다.** 시간, 처리량, 실패 누적 중 무엇으로 조일지 정해야 한다.
3. **통제를 잃는 방식이 필요하다.** 조작이 느려지거나, 입력이 안 먹거나, 정보가 사라지거나.
4. **실패에 대가가 있어야 한다.** 대가가 없으면 압박이 압박이 아니다.

> 위 넷은 전부 **코드·화면·사운드로만** 구현된다. 3D 예산을 쓰지 않는다.
