# [무제] 기획서

> 주차장 기획(v0.1~v0.6), 압박 기반 설계 방향은 폐기. 전체 이력은 git 히스토리에 있다.
> 제작 예산은 `docs/제작-제약.md` 참조.

## 1. 유지되는 것

- **장르**: 1인칭 공포
- **플랫폼**: PC / Unity (3D)
- **러닝타임**: 20분 이하 단일 세션
- **원칙**: 이상 요소는 **누적**시킨다

## 2. 폐기된 것

- 주차장이라는 무대 전체 — 부스·CCTV·순찰·딱지·차량·추격·야외 부지 등 여기 딸린 모든 설정.
- 압박 기반 설계 방향.

## 3. 확정된 것

- **무대**: 하수구. 좁고, 냄새나고, 습하고, 더럽다 — 이 인상을 전부 표현한다.
- **시점**: 핸드캠(캠코더) 시야.
- **진행 방식**: 8번 출구 인용. 앞에 양갈래 길이 나오면, 어떤 표시를 근거로 방향을 판단해 앞으로 나아간다.
- **플레이어 상태 변화**: 걸을수록 숨소리가 거칠어진다. 시야도 이상해진다.
- **위협 신호**: 옆에서 정체 모를 이상한 소리. 뒤에서도 반복적으로 이상한 소리가 들린다.
- **엔딩**: 앞에 빛이 보여서 뛰어간다 → 뒤에서 뭔가에게 습격당하며 잔인하고 그로테스크한 소리가 들린다 → 손에 든 캠이 떨어진다 → 캠 화면에 맨홀로 이어지는, 빛이 비치는 사다리가 비치며 끝난다.

### 3-1. `제작-제약.md`와 충돌하는 지점 (미해결, 사실 확인만)

- 엔딩의 "빛을 보고 뛰어간다"는 금지 목록의 **추격·도주·탈출 이동**에 해당한다.
- "양갈래 길"이 여러 구간으로 이어지면 **공간 1개 / 나가지 않는다** 조항과 충돌할 수 있다.
- "습격"을 시각적으로 보여주지 않고 사운드 + 캠 낙하 연출로만 처리하면 **위협은 보이지 않는 채로** 조건은 충족된다.
