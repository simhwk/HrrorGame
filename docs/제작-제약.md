# 제작 제약 (Production Budget)

> **목적**: 렌더링·에셋 비용을 바닥으로 눌러두고, 남는 힘을 전부 코딩과 연출에 쓴다.
> 이 문서의 숫자를 넘기는 아이디어는 채택하지 않는다.

---

## 1. 절대 예산

| 항목 | 한도 |
|---|---|
| **공간** | **3개** |
| **고유 3D 에셋** | **12종** |
| **캐릭터** | **1체** |
| **애니메이션** | **5개** |
| **광원 종류** | **2종** |
| **차량 모델** | **1종** (머티리얼 색상 변형만) |

### 1-1. 공간 3개
1. **부스** — 실내, 좁음
2. **주차장** — 야외, 20칸
3. **최종 공간** — 추격 종착지

이 외의 공간은 만들지 않는다. 이상현상으로 인한 "다른 장소"도 **위 3개의 변주로만** 표현한다.

### 1-2. 고유 3D 에셋 12종
차량 / 가로등 / 화단·나무 / 차단기 / 부스 외관 / 책상 / 모니터 / 키패드 / 무전기 / 근무일지 / 딱지 / 문

> 이 목록에 없는 것은 만들지 않는다. 새 소품이 필요한 아이디어는 기각하거나, 목록에서 하나를 뺀다.

### 1-3. 캐릭터 1체
- 사람 형상 하나. **얼굴 없음, 실루엣 수준.**
- 애니메이션 2개(서 있기 / 달리기)만 할당.
- 이 1체를 여러 상황에 재사용한다.

### 1-4. 광원 2종
- 가로등 (야외, 주황)
- 부스 실내등 (형광)

그 외는 **어둠**이다. 안 보이는 것은 만들지 않아도 된다 — 이것이 가장 큰 절약이다.

---

## 2. 핵심 규칙 — 이상현상은 "상태 변화"로만 만든다

**새 에셋을 요구하는 이상현상은 금지.** 이상현상은 아래 조작의 조합으로만 만든다.

| 조작 | 예 |
|---|---|
| 위치 이동 | 소품이 다른 자리에 있음 |
| 회전 | 차가 다른 방향을 보고 있음 |
| 개수 증감 | 가로등이 하나 늘거나 줄어듦 |
| 표시/숨김 | 있던 것이 없음 |
| 머티리얼 교체 | 색·질감이 달라짐 |
| 스케일 | 크기가 미묘하게 다름 |
| 복제 | 같은 것이 두 개 |

> 창의력은 "무엇을 새로 만들까"가 아니라 **"있는 것을 어떻게 틀까"** 에 쓴다.
> 이것은 절약일 뿐 아니라 리미널 호러의 본질이기도 하다 —
> 익숙한 것이 조금 틀어졌을 때가 새로운 것이 나타났을 때보다 무섭다.

---

## 3. 예산을 걸지 않는 영역 — 여기에 전부 쏟는다

| 영역 | 이유 |
|---|---|
| **사운드** | 가장 싸고 가장 강하다. 무제한 |
| **UI·화면 연출** | 텍스처와 셰이더로 만들어지므로 3D 비용 0. 공포 연출의 주력 |
| **타이밍·정적** | 비용 0. 페이싱 전부 |
| **스크립트·상태 관리** | 코딩 영역. 여기가 이 게임의 본체 |

---

## 4. 금지 목록

- 새 건물, 새 지형, 실내 공간 추가
- 얼굴 표정, 립싱크
- 물리 시뮬레이션 (천, 유체, 파괴)
- 다수의 NPC
- 컷신 전용 애니메이션
- 조작 방식이 새로 필요한 미니게임

---

## 5. 아이디어 채택 판정

새 아이디어가 나오면 순서대로 확인한다.

1. 새 3D 에셋이 필요한가 → **필요하면 기각** (또는 12종 중 하나와 교체)
2. 새 공간이 필요한가 → **필요하면 기각**
3. 새 애니메이션이 필요한가 → **5개 예산 안에서만**
4. 사운드·UI·타이밍으로 대체 가능한가 → **가능하면 그쪽으로**

> 1~3에 걸리지 않으면 자유롭게 채택한다. **제약 안에서는 제한이 없다.**
