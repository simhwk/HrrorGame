# 제작 제약 (Production Budget) — v2

> **목적**: 3D 제작 비용을 극단까지 눌러서, 남는 힘 전부를 코딩·사운드·화면 연출에 쏟는다.
> **이 문서는 무대를 정하지 않는다. 예산만 정한다.** 무엇을 채울지는 기획자가 정한다.
> 아래 숫자를 넘기는 아이디어는 채택하지 않는다.

---

## 1. 절대 예산

| 항목 | 한도 | 비고 |
|---|---|---|
| **공간** | **1개** | 플레이어는 이 공간을 **나가지 않는다** |
| **고유 3D 에셋** | **6종** | 무엇으로 쓸지는 미정 |
| **캐릭터 / 크리처** | **0체** | 사람도 괴물도 만들지 않는다 |
| **리깅 애니메이션** | **0개** | 모든 움직임은 코드로 처리 |
| **광원 종류** | **1종** | 그 외는 어둠 |
| **러닝타임** | **20분 이하** | |

### 1-1. 공간 1개
- 방 하나. **문을 나가는 연출조차 없다.**
- 로딩, 지형, 원경, 실외, 스카이박스 — 전부 없다.
- **"바깥"은 소리와 화면으로만 존재한다.**

### 1-2. 고유 3D 에셋 6종
- 방 자체(벽·바닥·천장)는 예산에 넣지 않는다. 박스 + 텍스처로 끝낸다.
- 그 안에 놓이는 물건이 **6종.** 목록은 기획자가 채운다.
- 7번째가 필요하면 **기존 6종 중 하나를 뺀다.**

### 1-3. 캐릭터 0체 ← 가장 중요한 제약
- 모델링·리깅·스키닝·애니메이션·AI·경로탐색이 **전부 사라진다.** 단일 항목 절감액이 제일 크다.
- 위협은 **보이지 않는 채로** 존재해야 한다. 소리, 그림자, 흔적, 화면 속 무언가, 상태 변화로만.
- 보여주지 않는 편이 더 무섭다는 것은 이 장르의 오래된 사실이다. 예산과 효과가 같은 방향이다.

### 1-4. 애니메이션 0개
- 리깅된 것은 만들지 않는다.
- 움직임이 필요하면 **코드로 트랜스폼을 옮긴다** — 위치, 회전, 스케일, 알파.
- 문이 열리고, 물건이 넘어지고, 조명이 흔들리는 정도는 전부 코드로 된다.

### 1-5. 광원 1종
- 조명 하나. 색·강도·깜빡임만 변주한다.
- 나머지는 어둠. **안 보이는 것은 만들 필요가 없다.**

### 1-6. 플레이어 이동
- 방 안으로 한정. 걸어서 3~4걸음 안에 어디든 닿는다.
- 이동 자체가 게임의 재미가 되어서는 안 된다.

---

## 2. 예산이 없는 영역 — 전부 여기에 쏟는다

| 영역 | 왜 무제한인가 |
|---|---|
| **사운드** | 3D 비용 0. 이 게임 공포의 절반 이상 |
| **화면·UI** | 모니터·패널에 뜨는 것은 3D가 아니라 UI다. **무한히 만들어도 공짜** |
| **셰이더·포스트프로세싱** | 노이즈, 왜곡, 글리치 — 에셋 없이 화면을 바꾼다 |
| **타이밍·정적** | 비용 0. 페이싱의 전부 |
| **코드·상태 관리** | 여기가 게임의 본체 |

> **탈출구는 화면이다.** 3D 물건은 6개뿐이지만, 그 안의 모니터에 띄우는 것은 제한이 없다.
> 공간이 좁을수록 화면의 무게가 커진다.

---

## 3. 이상현상 제작 규칙

**새 에셋을 요구하는 이상현상은 전부 기각.** 아래 조작의 조합으로만 만든다.

| 조작 | |
|---|---|
| 위치 이동 | 물건이 다른 자리에 있음 |
| 회전 | 방향이 틀어져 있음 |
| 개수 증감 | 하나 늘거나 줄어듦 |
| 표시 / 숨김 | 있던 것이 없음 |
| 머티리얼 교체 | 색·질감이 달라짐 |
| 스케일 | 크기가 미묘하게 다름 |
| 복제 | 같은 것이 둘 |
| 화면 내용 변경 | **무제한** |
| 사운드 | **무제한** |

> 창의력은 "무엇을 새로 만들까"가 아니라 **"있는 것을 어떻게 틀까"** 에 쓴다.

---

## 4. 금지 목록

- 두 번째 공간
- 사람·괴물 형상 (실루엣 포함)
- 리깅 애니메이션
- 물리 시뮬레이션 (천, 유체, 파괴)
- 추격, 도주, 탈출 이동
- 조작 방식이 새로 필요한 미니게임
- 컷신

---

## 5. 아이디어 채택 판정

1. 새 3D 에셋이 필요한가 → **기각** (또는 6종 중 하나와 교체)
2. 방을 나가야 하는가 → **기각**
3. 사람·괴물이 보여야 하는가 → **기각**
4. 리깅 애니메이션이 필요한가 → **기각**
5. 사운드·화면·셰이더·타이밍으로 되는가 → **그쪽으로**

> 1~4에 안 걸리면 마음대로 한다. **제약 안에서는 제한이 없다.**
